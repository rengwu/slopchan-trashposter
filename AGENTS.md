# UI rules

- Every visible control must work. If it looks clickable, draggable, adjustable, or selectable, it must perform that action and visibly reflect the resulting state. Otherwise remove it.
- No fake sequencer pads, decorative knobs, simulated meters, pretend menu items, or fabricated activity indicators. Display actual application state.
- Keep the playful DAW / Y2K styling, but never let the styling imply functionality that does not exist.
- Verify changed controls through their actual interactions, including keyboard access and persistence where applicable.
